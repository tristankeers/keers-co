# kci-v2: output changes against kci-v1

Generated by `scripts/kci_v2_changes.py` from KCI's 100-company dataset, which is used only as a fixed
test baseline. The engine formulas are unchanged; only the default assumptions differ. Companies with a
custom model saved in KCI (Dropbox) keep it in both versions.

## What changed

- Buyout priced at market EV plus a 30% premium on market equity; exit at the market multiple
- DCF uses the company's own beta and the live 10-year Treasury yield; no beta means no DCF
- Size premium 0% above $10bn market cap, 1% from $2bn to $10bn, 2% below $2bn
- Capex fades in a straight line from today's ratio (year 1) to the D&A ratio (final year)
