# kci-v3: output changes against kci-v2

Generated by `scripts/kci_v3_changes.py` from KCI's 100-company dataset, which is used only as a fixed
test baseline. kci-v3 keeps every kci-v2 change and adds the items below, which close the rest of the
22 Oct 2026 audit. Companies with a custom model saved in KCI (Dropbox) keep it, so the buyout tax cap and
the verdict rules do not apply to them.

## What changed

- Buyout interest deductible up to 30% of EBITDA a year; the excess carries forward
- DCF debt weight = gross debt / (gross debt + market equity); unknown capital structure means no DCF
- A Proceed on default assumptions is capped at Further Research until an analyst builds the case
- No default buyout verdict above 25x EV/EBITDA or below a 10% EBITDA margin (Pass: not a buyout candidate)
- DCF equity value and value per share withheld when enterprise value is zero or negative
- IRR flagged when the sponsor's cash flows change sign more than once
